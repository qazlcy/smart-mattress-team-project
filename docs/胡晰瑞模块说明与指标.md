# 胡晰瑞模块说明与指标

## 模块范围

本模块补全胡晰瑞负责的两项工作：

1. 身体部位划分：输出肩部、背部、腰部、臀部、大腿、小腿六个区域的行列边界、平均压力、最大压力和负载占比。
2. 体重预测：输出连续体重预测值、七个体重区间之一、预测来源和空载校正状态。

实现文件为 `body_weight.py`，已接入 `server.py` 的 `/api/replay` 接口，并在前端热力图上叠加区域框。

## 方法

- 区域划分优先使用本地课程 `区域划分/` 中的人工标注 JSON（兼容 `data.json` 与带日期/人数后缀的课程文件名），提取压力总载荷、接触面积、最大压力、平均压力和压力中心作为特征，通过标准化 KNN 选择最接近的区域模板。
- 如果本地没有区域标注 JSON，则退回到压力有效轮廓法，按人体纵向比例估计六个部位。
- 体重预测先使用用户级压力特征做岭回归标定，特征包括总载荷平方根、最大压力、按身高校正的载荷和压力中心。若新用户身高高于训练上界，改用训练集拟合的总载荷回归，避免多变量模型在范围外不稳定外推。
- 回归后使用训练用户的压力形态、接触范围和身高做一近邻序数校准。只有最近训练样本档位与回归档位恰好相邻时，才把连续预测收敛到该相邻档边界；相差两档及以上时拒绝校准。七档边界保持不变，测试用户的真实体重不参与模型拟合或校准。
- 空载校正读取每个用户目录下的 `*_空载.txt`，对推理帧做逐点基线扣除；没有空载文件时保留未校正结果并在接口中标明。
- 身体区域的已知用户验证按每位用户、每个动作的时间顺序做 70%/30% 分块，并在两段之间留一帧间隔；完全相同的压力帧只允许出现在一侧。新用户 `gzy` 从训练中完全隔离。
- 体重训练/测试使用 `docs/user_split.json` 中固定的随机种子 42 用户名单，与睡姿模块保持相同的 70%/30% 用户级划分。
- 原始数据、身高体重表和模型大文件不提交到仓库；运行时从本地数据目录读取。

## 复现命令

PowerShell：

```powershell
$env:MATTRESS_DATA_DIR = 'D:\智能床垫\睡姿 区域划分data\睡姿数据'
python scripts\evaluate_body_weight.py
python server.py
```

如果数据目录不在仓库同级位置，可显式指定：

```powershell
python scripts\evaluate_body_weight.py --data-root 'D:\智能床垫\睡姿 区域划分data'
```

## 当前指标

本地课程数据评估结果由 `scripts/evaluate_body_weight.py` 自动写入 `results/body_weight_results.json`。个体真实值和预测值仅写入已忽略的 `tmp/`，不会提交到公开仓库。

```json
{
  "region_known_boundary_accuracy_pct": 100.0,
  "region_new_user_boundary_accuracy_pct": 76.02,
  "region_train_evaluation_duplicate_frames": 0,
  "weight_new_user_count": 10,
  "weight_new_user_mae_kg": 3.55,
  "weight_interval_hit_rate_pct": 100.0,
  "weight_interval_or_adjacent_hit_rate_pct": 100.0,
  "weight_interval_or_adjacent_3kg_hit_rate_pct": 100.0,
  "weight_far_miss_rate_pct": 0.0,
  "weight_without_baseline_mae_kg": 5.45
}
```

区域主验收口径为六个身体部位边界容差准确率：行起点/终点允许 3/4 个传感器单元，列起点/终点允许 4/4 个单元；结果文件同时给出精确框准确率、IoU≥0.5 准确率和平均 IoU，避免只报告宽松指标。区域 JSON 中只有 `SAI`、`dgs`、`gzy` 三名用户存在完整区域标注，其余记录区域字段为 `na`。

体重结果以每名用户全部 21 个静态序列各前三帧的特征中位数为用户级预测。“严格命中”定义为预测与真实值处于同一档，或处于相邻档且绝对误差不超过 3 kg；该指标在 10 名隔离新用户上为 100%。单帧新用户 MAE 为 8.98 kg，因此实时页面将聚合结果标为正式结果，并把单帧值明确标为即时估计。空载校正将新用户 MAE 从 5.45 kg 降至 3.55 kg。
