# 数据集审计与集成接口

## 审计结论

- 原始压缩包包含 `睡姿数据/` 下 33 个以成员缩写命名的目录、每人 1--21 个采集文本和一个空载文本；另含 30 人区域划分 JSON 与热力图图片。
- 抽查课程静态采集文件：每行 24 个逗号分隔非负整数，连续 44 行合并为一个 `44 x 24` 压力帧；尾部不足一帧的数据忽略。该尺寸与睡姿 CNN 输入保持一致。
- 压力读数按 10-bit 满量程 1023 归一化并裁剪到 `[0,1]`；不能把实际可超过 255 的读数当作 8-bit 数据处理。
- `*_空载.txt` 可作为后续模型的基线校正输入。原始压缩包和解压数据不得提交到公开仓库。

## 启动

PowerShell 中指定已解压数据根目录（即包含 `lcy`、`nys` 等用户目录的 `睡姿数据`）：

```powershell
$env:MATTRESS_DATA_DIR = 'D:\path\to\睡姿数据'
python server.py
```

打开 `http://127.0.0.1:8000`。未设置数据目录时，服务自动使用内置合成帧，方便前端联调。

## 稳定接口

- `GET /api/users` 返回可选用户、数据目录状态。
- `GET /api/replay?user=lcy&sequence=1` 返回 `shape`、`frames`、逐帧 `metrics`、用户级 `stableWeightPrediction` 和数据来源。
- 每项 `metrics` 固定含 `maxPressure`、`averagePressure`、`contactAreaIndex`、`posture`、`postureSource`、四个 `airbags`、六个 `bodyRegions`、`weightPrediction` 与 `emptyBaselineApplied`。

完整训练会默认将 CNN 权重保存为 `results/cnn_state_dict.pt`，服务启动后自动加载它，`postureSource` 返回 `CNN 睡姿模型`。如需使用其他位置的权重，可设置 `MATTRESS_CNN_WEIGHTS`；权重缺失或无效时会明确返回规则回退原因，保证回放不会中断。气囊状态仍为可解释的压力分区规则。

`bodyRegions`、逐帧 `weightPrediction` 和用户级 `stableWeightPrediction` 来自胡晰瑞模块：本地存在课程区域标注和身高体重 `readme` 时使用标注近邻模型、压力回归、序数校准和空载校正；缺少私有数据时自动退回到演示估计。

`bodyRegions` 每项包含：

- `key` / `label`：部位英文键与中文名。
- `startRow`、`endRow`、`startCol`、`endCol`：在 `44 x 24` 压力矩阵中的区域边界。
- `meanPressure`、`maxPressure`、`loadShare`：区域压力统计。

`weightPrediction` 包含：

- `kg`：连续体重预测值。
- `interval`：七档体重区间，含 `index`、`label`、`low`、`high`。
- `source` / `confidence`：预测来源与是否使用本地校准。

`stableWeightPrediction` 包含 `userType`（训练库已有用户、30% 隔离新用户或演示用户）、`frameCount`、`formalResult` 和聚合后的 `prediction`。正式体重结果使用 21 个静态序列各前三帧的用户级特征中位数；逐帧 `weightPrediction` 只用于观察即时变化，不作为 MAE≤5 kg 的验收依据。
