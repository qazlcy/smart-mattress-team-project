# 数据集审计与集成接口

## 审计结论

- 原始压缩包包含 `睡姿数据/` 下 33 个以成员缩写命名的目录、每人 1--21 个采集文本和一个空载文本；另含 30 人区域划分 JSON 与热力图图片。
- 抽查 `lcy/lcy_1.txt`：每行 24 个逗号分隔非负整数，共 1348 行。集成服务按连续 56 行合并为一个 `56 x 24` 压力帧，尾部不足一帧的数据忽略。
- `*_空载.txt` 可作为后续模型的基线校正输入。原始压缩包和解压数据不得提交到公开仓库。

## 启动

PowerShell 中指定已解压数据根目录（即包含 `lcy`、`nys` 等用户目录的 `睡姿数据`）：

```powershell
$env:MATTRESS_DATA_DIR = 'D:\path\to\睡姿数据'
python server.py
```

打开 `http://127.0.0.1:8000`。未设置数据目录时，服务自动使用内置合成帧，方便前端联调。

## 稳定接口

- `GET /api/users` 返回可选用户、数据目录状态。
- `GET /api/replay?user=lcy&sequence=1` 返回 `shape`、`frames`、逐帧 `metrics` 和数据来源。
- 每项 `metrics` 固定含 `maxPressure`、`averagePressure`、`contactAreaIndex`、`posture`、`postureSource` 与四个 `airbags`。

当前 `posture` 与 `airbags` 是可解释的规则回退，明确标识为“等待模型接入”；队友模型交付后应保持字段不变，仅替换 `server.py` 的 `metrics()` 推理实现。
