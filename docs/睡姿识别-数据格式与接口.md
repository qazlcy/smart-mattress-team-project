# 睡姿识别：数据格式与接口

> 负责人：宁耀硕（数据处理与睡姿识别）
> 本文档定义睡姿识别的统一数据格式、标签字典、用户级训练/测试划分、数据增强、
> 模型接口与评价口径，供陆春雨（系统集成）与胡晰瑞（身体部位划分/体重预测）对接使用。

## 1. 数据审计结论

- 数据源：`睡姿数据/` 下 33 个用户目录（`dgs`、`nys`、`SAI` …），每人 21 个静态睡姿
  采集文本（序号 1–21）＋ `空载`（0）＋ `动态`（22，部分用户缺失，不影响静态分类）。
- **传感器矩阵为 44 行 × 24 列**。原始文本每行 24 个逗号分隔非负整数，连续 44 行
  合成一帧 `44×24` 压力矩阵。此前的 `server.py` 使用 56 行合成一帧，与本数据集实际
  尺寸不符，需在集成时对齐（见第 8 节）。
- 行数规律：静态睡姿 1–6、10–21 为 1320 行（30 帧）；俯卧类 7–9 为 2640 行（60 帧）；
  `空载` 为 660 行（15 帧）。1320/2640/660 均能被 44 整除，佐证 44 行为一帧。
- 文件前缀不一定等于目录名：`dwk1/` 下为 `dwk_1.txt`，`lxy1/`、`lzx1/`、`wc1/` 同理。
  解析时按文件名数字后缀（1–21）识别睡姿序号，而非假设 `{目录名}_{序号}`。
- 静态分类四类完全均衡：仰卧 5940 帧、俯卧 5940 帧、左侧卧 5940 帧、右侧卧 5940 帧
  （俯卧类每帧时长加倍，恰好与仅有 3 种俯卧睡姿相抵）。
- 采集读数按 10-bit 满量程（1023）归一化，并裁剪到 `[0,1]`；课程文件中可观察到超过 255 的读数，不能按 8-bit 量程处理。

## 2. 统一数据格式

- **原始**：`{用户目录}/{前缀}_{1..21}.txt`，每行 24 个整数，44 行一帧。
- **解析后**（供模型训练与推理）：
- `X`：`float32`，形状 `[N, 44, 24]`，数值范围 `[0, 1]`（除以 1023 后裁剪）。
  - `y`：`int32`，形状 `[N]`，粗分类索引 `0–3`。
  - 另保留 `posture`（细分类序号 1–21）与 `user_idx`（用户索引）以便追溯。
- 解析代码：`sleep_posture/data.py`（`parse_frames` / `load_dataset`）。

## 3. 标签字典

四类粗分类（即新版区域划分数据集的 `sleep_pose`），类别索引顺序即模型输出顺序：

| 类别索引 | 名称 | 对应细分类序号 | 细分类睡姿 |
| --- | --- | --- | --- |
| 0 | 仰卧 | 1–6 | 标准仰卧、左腿支撑、支撑翘腿、双腿交叉、双腿支撑、单腿外展 |
| 1 | 俯卧 | 7–9 | 直腿俯卧、张腿俯卧、双臂支撑 |
| 2 | 左侧卧 | 10–15 | 左直腿卧、左屈腿卧、左腿展开、左婴儿卧、左腿前屈、左侧俯卧 |
| 3 | 右侧卧 | 16–21 | 右直腿卧、右屈腿卧、右腿展开、右婴儿卧、右腿前屈、右侧俯卧 |

映射实现：`sleep_posture/labels.py`。`空载`(0) 与 `动态`(22) 不参与静态睡姿分类。

## 4. 用户级训练/测试划分

- 比例：**70% 用户训练（23 人）、30% 新用户测试（10 人）**；随机种子 `42`。
- 划分按**用户隔离**：同一用户的帧只出现在训练集或测试集之一，不与另一侧共享，
  以满足“新用户准确率”口径。

训练用户（23）：

```
zmw, lxy1, whl, lzx1, hxr, hyh, sbr, syz, ljy, SAI, ghx, lyp, gjh, lrc, lcy, wcy, dgs, dwk1, yl, ghb, wjy, wc1, zhr
```

测试用户（10，训练中未见）：

```
tjs, nys, whc, gzy, stanl, zxx, hpy, jhy, ltr, wzh
```

实现：`sleep_posture/data.py`（`split_users` / `split_dataset`）。

## 5. 数据增强

课程要求在原始数据基础上增强。对**训练集**施加标签无关增强，测试集不做增强：

1. 高斯噪声：加 `N(0, 0.012)`（约 ±3/255 的传感器量测噪声）；
2. 乘性缩放：整帧乘以 `[0.85, 1.15]` 内均匀随机系数，模拟不同体重的压强调制。

增强后的帧裁剪回 `[0,1]`。CNN/MLP 训练时把训练集与其一次增强副本拼接（数据量 ×2）；
SVM 使用原始训练特征（下采样后）不增强。实现：`sleep_posture/data.py`（`augment`）。

## 6. 模型接口

统一类别顺序：`[仰卧, 俯卧, 左侧卧, 右侧卧]`（索引 0–3）。预处理均为除以 255 归一化。

| 模型 | 输入 | 预处理 | 输出 |
| --- | --- | --- | --- |
| CNN（2D 卷积） | `[1, 44, 24]` | 除以 1023 后裁剪 | 4 类 logits（softmax 后为概率） |
| MLP（前馈） | `[1056]`（44×24 展平） | 除以 1023 后裁剪 | 4 类 logits |
| SVM（RBF） | `[264]`（2×2 下采样展平 + 标准化） | 除以 1023 后裁剪 → 下采样 → StandardScaler | 4 类类别标签 |

实现：`sleep_posture/models.py`（`CNN` / `MLP` / `fit_evaluate_svm`）。

## 8. 与集成端对接说明

- `server.py` 已使用 `ROWS = 44`，`/api/replay` 的 `shape` 字段随该常量自动输出，和模型输入保持一致。
- 睡姿推理接入方式：取一帧 `44×24` 原始值 → 除以 1023 并裁剪 → 送入 CNN → `argmax` 得到
  类别索引 → 映射为 `仰卧/俯卧/左侧卧/右侧卧`。`server.py` 的 `metrics()` 中 `posture`
  字段可直接替换为该结果，`postureSource` 改为 `"睡姿模型"`。
- 指标口径：默认按**单帧**评价（每帧独立分类）；如需时间窗口或用户级口径，另行标注。
