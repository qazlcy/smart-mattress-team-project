# 智能床垫课程设计 - 第三组

本仓库用于第三组完成智能床垫课程设计的团队协作与过程管理。当前仅保存项目分工和协作说明；代码、数据、模型、个人报告及个人 AI 会话记录将在成员实际完成后按任务提交。

## 选题

本组扩展功能选择 **体重预测算法的设计与实现**。项目同时完成课程规定的三项基础工作：

1. 不少于两种睡姿识别算法及其对比。
2. 身体部位划分算法。
3. 基于实时压力数据的智能床垫可视化展示。

完整分工、验收要求、协作规则见 [团队分工与协作](docs/团队分工与协作.md)。

## 陆春雨：集成与实时回放

已提供无需第三方依赖的压力帧回放服务和可视化页面：用户/采集序列切换、热力图、逐帧压力指标、睡姿状态及四区气囊联动。数据格式与接口约定见 [数据集审计与接口说明](docs/数据集审计与接口说明.md)。

## 协作原则

- 每项工作先建立 Issue，再从 `main` 创建分支开发；经组内另一位成员审核后通过 Pull Request 合并。
- 只提交实际完成的代码、文档和必要的可公开结果，不伪造提交、指标或 AI 会话记录。
- 原始压力数据、训练模型、账号凭据和个人完整 AI 会话记录不上传到公开仓库。
- 每个可复现结果须写明数据划分、随机种子、运行命令和评价口径。
